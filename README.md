# Streamlit-Workshop

- Link to the Streamlit workshop GitHub repo template: http://tiny.cc/eh-streamlit-template
- Create a GitHub account: https://github.com/

We will use GitHub Codespaces to develop our Streamlit apps. It is important to stop your Codespace when you are finished using it. Personal GitHub accounts include a monthly quota of free compute time and storage for Codespaces. Any usage beyond the included quota is billed to your account. If you do not have a valid payment method on file, you will be unable to use Codespaces after reaching the quota.  

| Account plan | Storage per month | Compute time per month |
| --- | --- | --- |
| GitHub Free for personal accounts | 15 GB-month | 120 hrs |
| GitHub Pro | 20 GB-month | 180 hrs |

More information about GitHub Codespaces billing:   
https://docs.github.com/en/billing/concepts/product-billing/github-codespaces
